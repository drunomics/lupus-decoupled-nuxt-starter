# Canvas Components

Reusable Vue components for Drupal Canvas page building. Registered globally via `nuxt.config.ts` and exposed to Canvas via [nuxt-component-preview](https://github.com/drunomics/nuxt-component-preview).

## Preview

Visit `/preview-components` to see all components rendered.

## Drupal Registration

When adding components or changing props/slots, re-register components in Drupal. No dev server restart needed.
